# 📊 Customer Churn Analysis System

## 📌 Overview
The **Customer Churn Analysis System** is a data analytics project that studies customer behavior using a synthetic dataset.  
It focuses on understanding why customers leave a service (customer churn) and identifying patterns that influence customer retention.

Since real customer data may not always be accessible due to privacy concerns, a **synthetic dataset containing 100,000 customer records** is generated and analyzed.  
The project applies **data preprocessing, exploratory data analysis (EDA), statistical analysis, and visualization techniques** to derive meaningful insights.

The findings help businesses improve customer satisfaction, reduce churn rates, and make data-driven decisions for customer retention strategies.

---

## 📂 Dataset
**Dataset Type:** Synthetic Dataset  

The dataset contains customer-related information such as:
- Customer ID  
- Age  
- Gender  
- Credit Score  
- Balance  
- Number of Products  
- Customer Activity Status  
- Churn Status

## 📋 Results
The system was successfully implemented using Python and synthetic customer data.

### Key Findings
- Customers with **low credit scores** are more likely to churn  
- Customers with **high account balances** show higher churn tendencies  
- **Inactive customers** have a significantly greater probability of leaving  
- **Product usage patterns** influence retention  
- **Demographics such as age** affect churn behavior  
- Visualizations highlighted customer behavior trends and risk factors

The **Customer Churn Analysis System** provides valuable insights into customer behavior and retention challenges.
